## 1. Visão Geral

**Krenko, Mob Boss** ({2}{R}{R})  
Criatura Lendária — Goblin Guerreiro  
{T}: Crie X fichas de criatura Goblin vermelha 1/1, onde X é o número de Goblins que você controla.  
3/3

**Plano de jogo otimizado (Early / Mid / Late)**

- **Early:** Acelerar Krenko o máximo possível (T3 ideal) com proteção e haste.
- **Mid:** Ativar Krenko repetidamente + lords + efeitos de dano por token + draw de volume.
- **Late:** Board gigante + Fiery Emancipation / Embercleave / Shared Animosity / infinitos leves ou dano massivo para fechar.

**Objetivo desta versão:**  
Chegar o mais perto possível do teto absoluto de poder em mono-red Goblins, aceitando linhas de alto poder e suporte genérico de elite.
